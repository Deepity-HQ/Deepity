Detailed Description

Sequential Predictive Coding Network.

The architecture is declared using Linear and Activation objects,
while optimization and inference parameters are supplied through
configure().

◆ _build_backend()

None deepity.SequentialPCN.SequentialPCN._build_backend ( self)
protected 
Translate the declarative architecture into backend PC layers.

Each Linear layer becomes a backend layer. If an Activation follows
it, that activation is attached to the backend layer. A final
terminal (sink) layer is appended so that the network's last layer
holds the OUTPUT dimension's beliefs, not the last Linear's input
dimension -- same pattern as SimplePCN._build_backend().

Train using I_avg initialization: each requested layer's
beliefs are seeded from that layer's per-class running mean
from the previous batch where that class appeared, instead of
zero-init every batch.

@param labels Integer class label per sample, same row order as X/Y.
@param per_class Examples per class per batch; see StreamAlignedBatcher.
@param num_classes Total number of distinct classes in labels.
@param cache_layers List of (layer_index, layer_size) pairs to
seed from their per-class cache.
@param reset_cache_per_epoch If True, clear every cache at the
start of each epoch; if False, caches persist across epochs.
