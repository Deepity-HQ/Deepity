\doxysubsection{Detailed Description}
Convolutional counterpart to Discriminative\+PCNetwork -- same public interface shape (Add\+Layer/\+\+Compile/\+\+Calculate\+State/\+\+Update\+State/\+ Update\+Weights/\+\+Train\+Step/\+\+Predict), wired to Conv\+PCLayer instead. 

Add\+Layer\textquotesingle{}s spatial dimensions (in\+Height/\+in\+Width) are NOT auto-\/inferred from the previous layer\textquotesingle{}s output shape -- pass them explicitly for each layer. This mirrors how every Conv\+PCLayer test this session specified shapes directly rather than relying on inference, and avoids a class of silent-\/shape-\/mismatch bug if a stride/\+padding choice doesn\textquotesingle{}t produce the dimension you expected.
