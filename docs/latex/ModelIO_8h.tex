\doxysubsection{Detailed Description}
Save/\+load support for persisting a Discriminative\+PCNetwork\textquotesingle{}s trained state to and from disk, as a structured directory rather than a single opaque binary blob. 

\begin{DoxyNote}{Note}
Layer weights and activation configuration are stored separately:\+ numeric weights go into a flat binary buffer (weights.\+bin), while per-\/layer metadata (sizes, activation types, hyperparameters) is expected to live in a human-\/readable manifest (manifest.\+json), with a generated README.\+md alongside for a human-\/readable summary. Activation\+To\+String()/\+\+String\+To\+Activation() are the round-\/trip conversion used when writing/\+reading that manifest. 
\end{DoxyNote}
