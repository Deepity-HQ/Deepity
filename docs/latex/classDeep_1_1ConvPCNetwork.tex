\doxysubsection{Detailed Description}
A convolutional Predictive Coding (PC) network:\+ an ordered stack of \doxylink{classDeep_1_1ConvPCLayer}{Conv\+PCLayer} instances sharing a single contiguous \doxylink{classDeep_1_1MemoryArena}{Memory\+Arena}, trained via iterative energy-\/relaxation rather than backpropagation. 

Mirrors \doxylink{classDeep_1_1DiscriminativePCNetwork}{Discriminative\+PCNetwork}\textquotesingle{}s public interface shape (Add\+Layer/\+\+Compile/\+\+Calculate\+State/\+\+Update\+State/\+\+Update\+Weights/\+ Train\+Step/\+\+Predict) so the two can generally be swapped for each other, but wires \doxylink{classDeep_1_1ConvPCLayer}{Conv\+PCLayer} instead of \doxylink{classDeep_1_1DiscriminativePCLayer}{Discriminative\+PCLayer}, making this the convolutional variant.

Typical usage:\+ 
\begin{DoxyCode}{0}
\DoxyCodeLine{Deep::ConvPCNetwork\ net(batchSize);}
\DoxyCodeLine{net.AddLayer(inChannels,\ outChannels,\ inHeight,\ inWidth,\ kernelH,\ kernelW);}
\DoxyCodeLine{\textcolor{comment}{//\ ...\ additional\ AddLayer()\ calls\ ...}}
\DoxyCodeLine{net.Compile();}
\DoxyCodeLine{net.RandomizeWeights(rng);}
\DoxyCodeLine{\textcolor{keywordtype}{float}\ energy\ =\ net.TrainStep(x,\ y,\ inferenceSteps);}

\end{DoxyCode}
