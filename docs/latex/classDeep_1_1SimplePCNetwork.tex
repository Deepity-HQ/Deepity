{\footnotesize\ttfamily \label{classDeep_1_1SimplePCNetwork_ae3d61db38519b08544a5efa1fc9b4744} 
void Deep::\+\+Simple\+PCNetwork::\+\+Project\+Forward (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})\hspace{0.3cm}{\ttfamily [noexcept]}}



Runs a single, non-\/iterative forward pass through current weights, seeding each hidden layer\textquotesingle{}s z from the PREVIOUS layer\textquotesingle{}s mu -- giving the settling loop a genuine, current-\/weights-\/based starting point instead of zero-\/init. 

Reuses each layer\textquotesingle{}s EXISTING \doxylink{classDeep_1_1SimplePCNetwork_a413894fb1d5b5da37159f1b728339e66}{Calculate\+State()} (already-\/verified forward computation, mu = f(W@z+b)) as a side effect -- no new math, just a new sequence of existing calls. Assumes the input layer (layers\+[0]\+) is ALREADY clamped before this is called.

\begin{DoxyWarning}{Warning}
\doxylink{classDeep_1_1Layer}{Layer} 0\textquotesingle{}s error (e) and this call\textquotesingle{}s energy return value are meaningless here -- \doxylink{classDeep_1_1SimplePCNetwork_a413894fb1d5b5da37159f1b728339e66}{Calculate\+State()} computes both mu (what we want) and e/\+energy (a side effect we\textquotesingle{}re discarding, since the NEXT layer\textquotesingle{}s z hasn\textquotesingle{}t been set to a meaningful value yet at the point each layer\textquotesingle{}s \doxylink{classDeep_1_1SimplePCNetwork_a413894fb1d5b5da37159f1b728339e66}{Calculate\+State()} runs). Only mu is used.
