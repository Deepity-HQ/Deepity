\doxysubsection{Detailed Description}
Standalone im2col /\+ col2im utilities:\+ convolution expressed as matrix multiplication, so Conv\+PCLayer can reuse cblas\+\_\+sgemm rather than needing hand-\/written conv kernels. 

VERIFIED:\+ passed t\+Conv\+Verify.\+cpp -- naive-\/reference comparison across three shape configurations (max error \texorpdfstring{$\sim$}{\string~}1e-\/6, float32 GEMM accumulation tolerance) AND an exact adjoint check (\texorpdfstring{$<$}{<}Wx,y\texorpdfstring{$>$}{>} == \texorpdfstring{$<$}{<}x,W\texorpdfstring{$^\wedge$}{\string^}\+Ty\texorpdfstring{$>$}{>}, \texorpdfstring{$\vert$}{|}diff\texorpdfstring{$\vert$}{|}=0), confirming Col2\+Im is the TRUE adjoint of Im2\+Col, not just a plausible-\/looking inverse-\/shaped operation. This matters because Conv\+PCLayer\textquotesingle{}s Update\+State() feedback term relies on that adjoint property the same way Discriminative\+PCLayer\textquotesingle{}s feedback term relies on W\texorpdfstring{$^\wedge$}{\string^}T being the genuine transpose.

Layout convention:\+ NCHW. A single batch item\textquotesingle{}s input is (channels, height, width), row-\/major, contiguous per channel.

im2col output shape:\+ (channels\texorpdfstring{$\ast$}{*}k\+H\texorpdfstring{$\ast$}{*}kW, out\+H\texorpdfstring{$\ast$}{*}outW) -- each column is one flattened receptive-\/field patch, ready to be GEMM\textquotesingle{}d against a (out\+Channels, channels\texorpdfstring{$\ast$}{*}k\+H\texorpdfstring{$\ast$}{*}kW) weight matrix to produce (out\+Channels, out\+H\texorpdfstring{$\ast$}{*}outW) in one matrix multiply.

col2im is the adjoint operation:\+ scatters a (channels\texorpdfstring{$\ast$}{*}k\+H\texorpdfstring{$\ast$}{*}kW, out\+H\texorpdfstring{$\ast$}{*}outW) gradient buffer back into a (channels, height, width) image, ACCUMULATING (does not zero the destination first -- caller must memset if needed).

Neither function knows anything about batching -- call once per batch item, with pointers offset to that item\textquotesingle{}s slice.

\begin{DoxyNote}{Note}
Each SIMD width (AVX-\/512/\+\+AVX2+\+AVX/\+\+SSE) is handled as a separate preprocessor branch with its own scalar-\/tail fallback along the stride-\/1 fast path; the strided (strideW != 1) path is always scalar, since a fixed vector width can\textquotesingle{}t align with an arbitrary stride. 
\end{DoxyNote}
