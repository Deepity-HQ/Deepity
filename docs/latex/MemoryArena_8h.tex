\doxysubsection{Detailed Description}
A 64-\/byte-\/aligned bump-\/pointer allocator over a single heap-\/allocated block, used to pack every layer\textquotesingle{}s beliefs/\+errors/\+ weights/\+scratch buffers into one contiguous region for cache locality (see the "{}\+Contiguous Arena Allocator"{} design note in the project README). Host-\/side counterpart to \doxylink{DeviceMemoryArena_8h}{Device\+Memory\+Arena.\+h}\textquotesingle{}s CUDA version. 

\begin{DoxyNote}{Note}
Individual chunks handed out by Allocate\+Floats() cannot be freed independently -- the entire arena is released at once in the destructor, matching the bump-\/pointer/\+no-\/reclaim design used throughout this codebase\textquotesingle{}s memory arenas. 
\end{DoxyNote}
