inlinenoexcept

Vectorized PLAIN Adam update over n elements – NO weight decay term at all, unlike AdamWUpdate above. This is deliberate, not a missing feature: "Adam with L2 regularization" (folding decay into the gradient before the moment estimates see it) is the well-known WORSE approach AdamW was specifically invented to fix – large-gradient weights get decayed less than they should, since the adaptive step size shrinks the decay term along with everything else. If you want regularization alongside plain Adam, apply this codebase's existing decay convention separately (e.g. cblas_sscal(n, 1.0f-lmbda, w, 1) before calling this) – fully composable, and avoids re-introducing the exact problem AdamW exists to solve.

Same per-element m/v semantics as AdamWUpdate: one m/v pair PER WEIGHT, t is the layer's own shared timestep counter (increment ONCE per UpdateWeights() call, not per element).

Parameters
wWeight (or bias) array of length n; updated in place.
gradRAW, unscaled gradient array of length n (NOT pre-scaled by lr or batch size – see file-level warning).
mFirst-moment (mean) estimate array of length n; updated in place. One entry per weight.
vSecond-moment (uncentered variance) estimate array of length n; updated in place. One entry per weight.
nNumber of elements in w / grad / m / v.
tThis layer's shared timestep counter, incremented once per UpdateWeights() call (not per element).
lrLearning rate.
beta1Exponential decay rate for the first-moment estimate. Defaults to 0.9.
beta2Exponential decay rate for the second-moment estimate. Defaults to 0.999.
epsNumerical-stability constant added to the denominator. Defaults to 1e-8.

inlinenoexcept

Vectorized AdamW update over n elements. w, grad, m, v are all arrays of length n – ONE m/v pair PER WEIGHT, not one shared scalar. t is the layer's own timestep counter (increment ONCE per UpdateWeights() call, not per element – shared across the whole array, which is why beta1^t/beta2^t are computed once here, not per element).

AdamW's decoupled weight decay (w -= lr*lambda*w, applied separately from the gradient-based step) replaces this codebase's existing cblas_sscal(..., 1.0f-lmbda, W, 1) weight-decay call – don't apply both, or decay will be applied twice.

Parameters
wWeight (or bias) array of length n; updated in place.
gradRAW, unscaled gradient array of length n (NOT pre-scaled by lr or batch size – see file-level warning).
mFirst-moment (mean) estimate array of length n; updated in place. One entry per weight.
vSecond-moment (uncentered variance) estimate array of length n; updated in place. One entry per weight.
nNumber of elements in w / grad / m / v.
tThis layer's shared timestep counter, incremented once per UpdateWeights() call (not per element).
lrLearning rate.
lambdaDecoupled weight-decay coefficient (AdamW-style, applied directly to w, not folded into the gradient).
beta1Exponential decay rate for the first-moment estimate. Defaults to 0.9.
beta2Exponential decay rate for the second-moment estimate. Defaults to 0.999.
epsNumerical-stability constant added to the denominator. Defaults to 1e-8.

The adjoint of Im2Col(): scatters a (channels*kH*kW, outH*outW) column-gradient buffer back into a (channels, height, width) image.

Verified (see file-level note) to be the TRUE mathematical adjoint of Im2Col(), not just an inverse-shaped operation – this is what makes it safe to use for ConvPCLayer's feedback term.

Parameters
columnsInput buffer of shape (channels*kH*kW, outH*outW), typically a gradient produced by a GEMM against the same weight matrix used in the forward Im2Col() pass.
channelsNumber of output-image channels.
heightOutput image height (the original pre-Im2Col input height).
widthOutput image width (the original pre-Im2Col input width).
kHKernel height.
kWKernel width.
strideHVertical stride.
strideWHorizontal stride.
padHVertical zero-padding.
padWHorizontal zero-padding.
outputImageOutput buffer of shape (channels, height, width). ACCUMULATED into (values are added, not overwritten) – the caller must zero this buffer first if a fresh result is wanted.
Warning
Not batch-aware – call once per batch item, with columns and outputImage offset to that item's slice.
Accumulates into outputImage rather than overwriting it; failing to memset the destination first will add this call's result on top of whatever was already there.

void Deep::Im2Col ( const float * input,
int channels,

int padW,

inlinenoexcept

Rearranges a single (channels, height, width) input image into a (channels*kH*kW, outH*outW) column matrix, where each column holds one flattened receptive-field patch – the standard im2col transform that lets convolution be computed as a single GEMM against a (outChannels, channels*kH*kW) weight matrix.

Positions that fall outside the input (due to padding) are written as zero.

Parameters
inputPointer to a single batch item's input image, layout (channels, height, width), row-major, contiguous per channel.
channelsNumber of input channels.
heightInput image height.
widthInput image width.
kHKernel height.
kWKernel width.
strideHVertical stride.
strideWHorizontal stride.
padHVertical zero-padding.
padWHorizontal zero-padding.
columnsOutput buffer of shape (channels*kH*kW, outH*outW), fully overwritten (not accumulated into). Must be preallocated by the caller with size computed from ConvOutDim().
Warning
Not batch-aware – call once per batch item, with input and columns offset to that item's slice.
