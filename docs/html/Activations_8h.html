Detailed Description

Defines the activation functions of a predictive coding model.

This header includes implementations of ReLU and TanH.

Usage: #include <deepity/Activations.h>

Example: Deep::tanh(array, arraysize)

Note
Separate implementations exist for AVX512F, AVX2, SSE, and naive. Memory does NOT need to be aligned.
