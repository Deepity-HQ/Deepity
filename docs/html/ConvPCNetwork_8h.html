Detailed Description

Convolutional counterpart to DiscriminativePCNetwork – same public interface shape (AddLayer/Compile/CalculateState/UpdateState/ UpdateWeights/TrainStep/Predict), wired to ConvPCLayer instead.

AddLayer's spatial dimensions (inHeight/inWidth) are NOT auto-inferred from the previous layer's output shape – pass them explicitly for each layer. This mirrors how every ConvPCLayer test this session specified shapes directly rather than relying on inference, and avoids a class of silent-shape-mismatch bug if a stride/padding choice doesn't produce the dimension you expected.
