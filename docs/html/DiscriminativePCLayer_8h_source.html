226/*
227 * MHSA USING PCNs:
228 * In a standard Transformer, Multi-Head Self-Attention (MHSA) computes Queries, Keys,
229 * and Values in a rigid, one-shot forward pass to route token context. If implemented
230 * using a PCN, the attention scores and context vectors would become dynamic latent
231 * states (z). When a sequence is input, the attention routing wouldn't be calculated
232 * instantly; instead, it would iteratively settle over artificial time. The network
233 * would adjust its attention states to minimize the prediction error between the
234 * bottom-up token data and the top-down expectations from higher layers. The Q, K,
235 * and V projection matrices would serve as the local weights (W) for this mechanism,
236 * and would be updated entirely in parallel via local Hebbian rules once the attention
237 * routing reached its minimum-energy equilibrium.
238 */
