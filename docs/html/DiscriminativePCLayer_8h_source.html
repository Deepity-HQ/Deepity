317/*
318 * MHSA USING PCNs:
319 * In a standard Transformer, Multi-Head Self-Attention (MHSA) computes Queries, Keys,
320 * and Values in a rigid, one-shot forward pass to route token context. If implemented
321 * using a PCN, the attention scores and context vectors would become dynamic latent
322 * states (z). When a sequence is input, the attention routing wouldn't be calculated
323 * instantly; instead, it would iteratively settle over artificial time. The network
324 * would adjust its attention states to minimize the prediction error between the
325 * bottom-up token data and the top-down expectations from higher layers. The Q, K,
326 * and V projection matrices would serve as the local weights (W) for this mechanism,
327 * and would be updated entirely in parallel via local Hebbian rules once the attention
328 * routing reached its minimum-energy equilibrium.
329 */
