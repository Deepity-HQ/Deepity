Fills the next batch into caller-provided, pre-allocated output buffers. Rows are GROUPED by class: rows [0, perClass) are class 0, [perClass, 2*perClass) are class 1, etc. – same convention as the Python version, so per-class slicing for cache-averaging is a trivial contiguous range.

Parameters
