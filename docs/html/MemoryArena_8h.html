Detailed Description

A 64-byte-aligned bump-pointer allocator over a single heap-allocated block, used to pack every layer's beliefs/errors/ weights/scratch buffers into one contiguous region for cache locality (see the "Contiguous Arena Allocator" design note in the project README). Host-side counterpart to DeviceMemoryArena.h's CUDA version.

Note
Individual chunks handed out by AllocateFloats() cannot be freed independently – the entire arena is released at once in the destructor, matching the bump-pointer/no-reclaim design used throughout this codebase's memory arenas.
