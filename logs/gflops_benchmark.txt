Deepity GFLOPS benchmark, CPU (12th Gen Intel Core i7-12700H, native + MKL build).
Command: ninja GflopsBenchmark && ./bin/GflopsBenchmark
Measures sustained GFLOPS for a full PC train step (SimplePCN, 784-512-256-64-10,
batch=256, T=20 settling steps). FLOP accounting documented in tests/tGflopsBenchmark.cpp.

CORRECTED after fixing a CMakeLists.txt bug: see logs/activation_benchmark.txt for the
full explanation -- same root cause (test executables missing -march=x86-64-v3) applies
here too, since Deep::sigmoid() runs inside this network's layers every settling step.
This run is through the normal build (ninja GflopsBenchmark), not a manual workaround.
Note: this is a laptop with CPU frequency scaling enabled -- re-running shows real
run-to-run variance, not a fixed number.
